# 青年心盾内容分析助手浏览器插件 MVP

这是一个 Chrome / Edge 浏览器插件初版，用来验证“进入抖音、微博、文章等页面后，基于当前页面 URL 在插件弹窗内直接生成内容风险分析结果”的插件形态。

## 当前能力

- 自动读取当前标签页 URL、标题和页面摘要。
- 点击插件后自动分析当前内容，无需手动确认 URL。
- 插件弹窗内可点击“固定悬浮球”，在当前网页中常驻一个可拖动的小圆球。
- 点击悬浮球可展开分析结果面板，拖动悬浮球可调整位置。
- 固定悬浮球开启后，打开新的页面会自动读取新页面 URL 并刷新分析。
- 优先调用本地后端接口 `http://localhost:8000/analyze`。
- 如果当前是本地 `file://` 页面或后端不可用，会使用插件内置演示数据兜底。
- 分析结果直接显示在插件弹窗内，展示类似主分析页的内容：
  - 内容预览
  - 识别标签
  - 风险评级
  - 叙事分析
  - 关联案例

## 加载方式

1. 打开 Chrome 或 Edge 扩展管理页面。
2. 开启“开发者模式”。
3. 点击“加载解压缩的扩展程序”。
4. 选择本文件夹：`visual-ai-extension`。

## 本地 file 页面说明

如果当前页面是类似：

```text
file:///C:/Users/29488/Desktop/%E9%A1%B9%E7%9B%AE/frontend/index.html
```

需要在扩展详情页里开启：

```text
允许访问文件网址
```

否则插件可能无法把分析浮层注入到本地页面。

## 使用流程

1. 打开抖音、微博、B站、文章页，或本地 `frontend/index.html`。
2. 点击浏览器右上角插件图标。
3. 插件会自动读取当前页面 URL，并直接在弹窗内显示分析结果。
4. 点击“固定悬浮球”后，网页内会出现可拖动小圆球；点击圆球展开分析结果，切换页面后会自动重新分析当前页面。
