## 五、安装 MySQL

（若服务器已装 MySQL，`mysqld --version` 有输出即可跳过本节。）

更新软件源并安装 MySQL 8.0：

```bash
apt update
apt install -y mysql-server
```

安装过程若弹出紫色配置框「**Daemons using outdated libraries / Which services should be restarted?**」：按 `Tab` 移到 `<Ok>`，回车确认即可（用默认选项，无需改动）。

安装完成后确认版本与运行状态：

```bash
mysqld --version
systemctl status mysql --no-pager
```

预期：版本 `8.0.xx`；状态 `active (running)`。若未运行：`systemctl start mysql`。

> 按 `q` 可退出 `systemctl status` 的翻页界面。

预期：无任何报错、直接回到提示符即成功。脚本内含 `CREATE DATABASE youth_ideology` + 13 张 `CREATE TABLE`。

## 八、如何插入数据（灌数据）

> 前提：第六节已建好表结构。数据文件为本机 `青少年风险预测前后端/db/data/` 下的 9 个 `.sql`（每个含 `USE youth_ideology;` + 该表 `INSERT`，可直接执行）。
> 有数据的 9 张表：`t_risk_label`(259) / `t_corpus`(59412) / `t_case`(60) / `t_ai_script`(201) / `t_domain_keyword`(255) / `t_domain_template`(40) / `t_l1_taxonomy`(16) / `t_l2_taxonomy`(34) / `t_l3_taxonomy`(50)。其余 4 张为运行时表，保持空即可。

### 方式一：上传数据文件到服务器后导入（推荐，最稳）

**① 本机把整个 data 目录传到服务器** `/root/data/`：

```bash
scp -r "青少年风险预测前后端/db/data" root@47.99.104.11:/root/
```

**② SSH 登录服务器**：

```bash
ssh root@47.99.104.11
```

**③ 逐表导入**（服务器上执行，root 免密；先导小表/字典，再导大表语料）：

```bash
mysql youth_ideology < /root/data/t_l1_taxonomy.sql
mysql youth_ideology < /root/data/t_l2_taxonomy.sql
mysql youth_ideology < /root/data/t_l3_taxonomy.sql
mysql youth_ideology < /root/data/t_risk_label.sql
mysql youth_ideology < /root/data/t_domain_keyword.sql
mysql youth_ideology < /root/data/t_domain_template.sql
mysql youth_ideology < /root/data/t_case.sql
mysql youth_ideology < /root/data/t_ai_script.sql
mysql youth_ideology < /root/data/t_corpus.sql
```

> `t_corpus.sql` 约 83MB / 5.9 万行，导入需十几秒到几十秒，属正常。
> 表间为软关联（无外键约束），导入顺序其实不影响，按上面顺序更直观。

**一次性全导（可选，替代逐条）**：目录内文件按文件名排序依次导入，每个文件自带 `USE`：

```bash
cat /root/data/*.sql | mysql
```

### 方式二：本机直连远程 MySQL 导入（无需上传文件）

需先完成第九节「建专用账号 + 安全组放行 3306 + 开启远程监听」。在**本机**执行：

```bash
mysql -h 47.99.104.11 -P 3306 -u ys_app -p youth_ideology < "青少年风险预测前后端/db/data/t_risk_label.sql"
```

（其余表同理，把文件名替换即可；`-p` 后回车会提示输入该账号密码。）

### 验证每张表已灌入

```bash
mysql -e "USE youth_ideology;
SELECT 't_corpus' AS 表, COUNT(*) AS 行数 FROM t_corpus
UNION ALL SELECT 't_risk_label', COUNT(*) FROM t_risk_label
UNION ALL SELECT 't_case', COUNT(*) FROM t_case
UNION ALL SELECT 't_ai_script', COUNT(*) FROM t_ai_script
UNION ALL SELECT 't_domain_keyword', COUNT(*) FROM t_domain_keyword
UNION ALL SELECT 't_domain_template', COUNT(*) FROM t_domain_template
UNION ALL SELECT 't_l1_taxonomy', COUNT(*) FROM t_l1_taxonomy
UNION ALL SELECT 't_l2_taxonomy', COUNT(*) FROM t_l2_taxonomy
UNION ALL SELECT 't_l3_taxonomy', COUNT(*) FROM t_l3_taxonomy;"
```

预期行数：t_corpus 59412、t_risk_label 259、t_case 60、t_ai_script 201、t_domain_keyword 255、t_domain_template 40、t_l1_taxonomy 16、t_l2_taxonomy 34、t_l3_taxonomy 50。

### 重新导入 / 清空某表再导

数据文件是 `INSERT`，重复执行会因主键重复报错。若要重导某张表，先清空再导：

```bash
mysql -e "USE youth_ideology; TRUNCATE TABLE t_case;"
mysql youth_ideology < /root/data/t_case.sql
```

> ⚠️ `TRUNCATE` 会清空该表全部数据，确认后再执行。

### 对方自行写入数据

若不用现成文件，对方也可按表结构直接写 `INSERT`，例如：

```sql
USE youth_ideology;
INSERT INTO t_l1_taxonomy (l1_code, l1_name, sort_order) VALUES ('L1-1', '示例一级风险域', 1);
```

字段含义见《数据库设计说明.md》或 `SHOW CREATE TABLE 表名;`。

## 九、收尾与安全

**1. 修改服务器密码**（部署时若在公开渠道发过密码，务必更换）：

```bash
passwd root
```

**2. 为对方开放数据写入（二选一）**

方式 A —— 让对方也用 SSH 登录服务器，本机 `mysql` 直接操作（简单，但共享 root）。

方式 B —— 建专用数据库账号，供对方远程连接（推荐，不共享 root）。示例（把密码换成强密码）：

```sql
-- 在服务器上执行： mysql  然后粘贴以下 SQL
CREATE USER 'ys_app'@'%' IDENTIFIED BY '在此填强密码';
GRANT SELECT, INSERT, UPDATE, DELETE ON youth_ideology.* TO 'ys_app'@'%';
FLUSH PRIVILEGES;
```

同时需：① 阿里云控制台**安全组放行 3306** 端口；② MySQL 允许远程监听（编辑 `/etc/mysql/mysql.conf.d/mysqld.cnf`，把 `bind-address` 改为 `0.0.0.0` 后 `systemctl restart mysql`）。

**3. 对方填数据的方式**

- 用现成的数据文件：`mysql youth_ideology < 表名.sql`（对应 `db/data/*.sql`）。
- 或按表结构自行写入 `INSERT`。

**4. 退出服务器**

```bash
exit
```

## 十、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `scp` / `ssh` 卡住或 `Connection timed out` | 阿里云安全组未放行 22 端口，或公网不通 |
| `Permission denied` | 密码错误 |
| 安装弹紫色 needrestart 框 | 正常，`Tab` 到 `<Ok>` 回车即可 |
| `mysql: command not found` | 未装 MySQL，执行第五节安装 |
| 导入报 `Unknown collation 'utf8mb4_0900_ai_ci'` | 目标是 MySQL 5.7 / MariaDB，把脚本内该排序规则替换为 `utf8mb4_unicode_ci` |
| 想确认表结构 | `mysql -e "USE youth_ideology; SHOW CREATE TABLE t_corpus\G"` |
